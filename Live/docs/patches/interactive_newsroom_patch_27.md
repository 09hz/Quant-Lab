# Patch 27 — Interactive Newsroom Foundation

Turns the Newsroom from a static source page into an interactive read-only research workspace.

## Features

- Topic input
- Source filters
- Clickable trusted-source research links
- Select results
- Add selected results to a research brief
- Export brief as JSON
- Export brief as Markdown

## Safety

No broker access, no order placement, no unrestricted browsing, and no browser secret entry.

This patch uses deterministic clickable searches first. API-backed FRED/SEC/BLS/BEA connectors can be added later after the UI is stable.
