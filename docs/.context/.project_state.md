# Project Overview

AlgoTrader is an AI-assisted quantitative research platform focused on historical market analysis, strategy development, and backtesting.

This project is intended for research and simulation only.

Live trading, broker integration, and automatic order execution are intentionally excluded unless explicitly added in the future.
