# AlgoTrader Architecture

Last Updated: 2026-07-15

---

# Mission

AlgoTrader is an AI-assisted quantitative research platform.

The platform is designed for

- Historical market analysis
- Strategy research
- Backtesting
- Walk-forward validation
- Portfolio analysis
- Experiment management

The platform is NOT intended for

- Live trading
- Broker connectivity
- Order routing

unless explicitly added in the future.

DatabaseConnectionManager

↓

↓

SQLite/PostgreSQL

Migration Strategy

Maintain backwards compatibility.

Replace only the implementation.

Avoid modifying application modules until compatibility layer is complete.

---

# Engineering Principles

Always

- Preserve backwards compatibility.
- Prefer services.
- Prefer providers.
- Keep modules loosely coupled.
- Build incrementally.
- Create self tests.
- Compile before merging.

Never

- Rewrite working systems.
- Duplicate business logic.
- Hardcode secrets.
- Store passwords in JSON.
