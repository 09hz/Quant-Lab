# Database Architecture

Last Updated: 2026-07-15

---

# Mission

AlgoTrader supports two database backends.

• SQLite

• PostgreSQL

The application should operate identically regardless of backend.

Database access must be centralized.

---

# Current Architecture

Application

↓

DatabaseConnectionManager

↓

Database Provider

↓

SQLite

or

PostgreSQL

---

# DatabaseConnectionManager

Responsibilities

• Load configuration

• Load credentials

• Select provider

• Open connections

• Manage connection lifecycle

• Provide application-wide database access

Application modules should not open connections directly.

# Configuration

Configuration is stored in

Live/data/private/db_connection.json

Configuration includes

Backend

Host

Port

Database

User

Schema

Remember Password

Passwords are NOT stored here.

# Database Rules

Always

Use DatabaseConnectionManager.

Never

Call sqlite3.connect()

outside SQLiteProvider.

Never

Call psycopg.connect()

outside PostgreSQLProvider.

Never

Store passwords in JSON.

Never

Duplicate connection logic.
